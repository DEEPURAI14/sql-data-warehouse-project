# Data Warehouse and Analytics Project 🚀
03
Welcome to the Data Warehouse and Analytics Project!

This project shows how to collect, clean, and combine data from different sources into one data warehouse. It also uses SQL to analyze data and find useful business insights. This project is created for learning and portfolio purposes.

## 🚀 Project Requirements

## 1. Building the Data Warehouse (Data Engineering)

**Objective**

Create a modern data warehouse using SQL Server to store sales data in one place. This helps businesses analyze data and make better decisions.

**Specifications**

- **Data Sources:** Import data from two systems (ERP and CRM) using CSV files.
- **Data Cleaning:** Find and fix errors, missing values, and duplicate records.
- **Data Integration:** Combine data from both sources into one organized data model.
- **Scope:** Work only with the latest data. Storing historical data is not required.
- **Documentation:** Explain the data model clearly so that both business users and data analysts can understand it.

---

### 2. BI: Analytics and Reporting (Data Analytics)

**Objective**

Use SQL to analyze data and generate useful business insights.

**Main Areas of Analysis**

- **Customer Behavior:** Understand customer needs and buying patterns.
- **Product Performance:** Identify the best-selling and most profitable products.
- **Sales Trends:** Analyze sales growth and changes over time.

These insights help businesses understand their performance and make better decisions.
